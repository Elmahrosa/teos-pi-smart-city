# Pi Console assets — Elmahrosa Smart City

Suggested app name: **Elmahrosa Smart City**  
Category: **Utilities / Civic**  
Short description (under 90 characters): **Alexandria civic vision demo for community proposals and smart services.**

## Long description

An Arabic-first civic smart city concept for Alexandria, Egypt, built as a Pi Next Hackathon 2026 demo. Explore illustrative districts, community proposals, a concept map, and a transparent-demo treasury view. Pi sign-in uses the Pi Browser SDK. The petition support UI is a local sandbox simulation and does not create a Pi transaction. No land is offered for sale; no shares, financial returns, or investment are offered. All map and governance activity shown is demo content, not live public-service data.

## Icon concept

A simple navy shield enclosing a gold city skyline and a subtle Pi-inspired circular accent. Use original artwork and avoid implying official Pi Network endorsement.
